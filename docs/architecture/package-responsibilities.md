# Package Responsibilities

## @ryvra/ui

Typed, minimal design primitives and theme tokens used by app shells.

## @ryvra/auth

Session/user/role contracts, auth guard interfaces, and stub guard implementation.

## @ryvra/api-client

Typed boundary clients for Markets, Pay, and Points/Tasks with transport abstraction, normalized errors, and mock adapter mode.

## @ryvra/config

Environment schema parsing, typed feature flags, and app-specific config loaders.

## @ryvra/domain-tokenomics

Framework-agnostic DTOs and pure helper stubs for eligibility, daily caps, epoch metadata, and conversion preview.

## @ryvra/domain-payments

Framework-agnostic DTOs and helper stubs for invoices, payouts, subscriptions, idempotency, and reconciliation status.

## @ryvra/domain-markets

Framework-agnostic DTOs for assets, orders, positions, risk limits, and execution intents.

## @ryvra/observability

Logger contracts, console logger implementation, span/trace placeholders, and error taxonomy mapping stubs.
